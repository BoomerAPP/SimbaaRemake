# SIMBAA Fresh v22

Rilis v22 dibangun dari source v21 dengan mempertahankan tema, struktur Supabase, autentikasi, dan data katalog. Tidak ada migrasi atau penghapusan data.

## File utama
- `index.html`, `layanan.html`, `promo.html`, `tentang.html`, `bantuan.html`
- `style.css`, `app.js`
- `Simbaa.html`
- `admin/admin.css`, `admin/admin.js`

## Pembaruan
Lihat `CHANGELOG-v22.md` dan `QA-REPORT-v22.md`.

## Deploy
Unggah isi folder ini ke deployment yang sama seperti versi sebelumnya. Pertahankan `supabase-config.js` dan seluruh aset. Tidak ada SQL baru yang perlu dijalankan.

Setelah deploy, uji login admin, CRUD produk/kategori/promo/banner/portofolio/testimoni/FAQ/pengumuman, upload aset, panel notifikasi toolbar, checkout, template WhatsApp, serta tautan footer.
